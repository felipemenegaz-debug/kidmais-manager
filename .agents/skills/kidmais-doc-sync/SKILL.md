# Sincronização documental

1. Use `docs/README.md` para localizar a fonte oficial do tema.
2. Compare a mudança com regras de negócio, documento do módulo, arquitetura, ADRs, roadmap e changelog funcional aplicáveis.
3. Atualize somente a fonte canônica: comportamento vigente no documento do módulo/regra, decisão durável em ADR, planejamento no roadmap e mudança entregue no changelog.
4. Preserve histórico e evite duplicar grandes blocos entre documentos; use links quando adequado.
5. Se nenhuma atualização for necessária, registre o motivo. Não altere documentação para encobrir divergência não aprovada entre código e regra oficial.
